## Track 5 — Build and format (the two-PDF strategy)

**Fact, verified 2026-07-12 against the TMLR author guide**: submissions must be PDFs generated with the official `tmlr.sty` + `tmlr.bst` (LaTeX2e); modifying the style files may be grounds for rejection; Computer Modern Bright typeface; no length limit but length must be justified; appendix goes after references; up to 100MB supplementary material permitted.

Consequence: the house pandoc → lualatex PDF/UA-2 pipeline (Atkinson Hyperlegible, tagged figures, accessible captions) **cannot be the submission build**. Proposed resolution — two build targets from the same markdown sections:

1. **Submission build**: pandoc emits a LaTeX *body* that `\input`s into the official `tmlr.tex` shell, untouched `tmlr.sty`, BibTeX with `tmlr.bst`, anonymized. New build script target; moderate one-time work, mostly template plumbing.
2. **Accessible build**: the existing PDF/UA-2 pipeline, retained for trishasalas.com, Zenodo preprint, and camera-ready-adjacent distribution. TMLR permits preprints at any time (CC BY 4.0, authors retain copyright) provided the submission never links to a version bearing names. Post-publication someday-pile: a **plain-language edition** built from the PLAIN-COMPANION approach, framing device "the rooster problem" (Trisha's metaphor, 2026-07-12 — devs who crow loudest about code that's lame = models whose confidence tracks fluency, not knowledge; §5's calibration collapse for practitioners). Cognitive accessibility applied to scholarship, on-brand for the program.
3. **The on-brand move**: include an **anonymized copy of the accessible PDF as supplementary material**. The accessibility paper arrives with an accessible version of itself; reviewers who need it have it; the gesture is the thesis. (Verify the anonymized-supplementary rules permit a second PDF; they permit data/code/video, and a PDF is uncontroversial.)

Also under this track: the citation pass (Track 1, pass 4) now has a concrete target — convert the reference shelf to a `.bib`, natbib citations in text.
